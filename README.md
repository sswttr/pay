# pay · 还款

一个记录每月贷款还款和个人借款的小网页，可以添加到手机主屏幕，像 App 一样打开。

- **贷款**：银行 + 贷款种类、还款日、每月还款额，每月勾选「已还」；还款日历；可调整顺序。
- **个人**：债权人、借款时间、金额、已还、未还，末行合计。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库，名字填 `pay`（建议设为 **Public**，免费账号的 Pages 需要公开仓库）。
2. 把本文件夹里的所有文件上传到仓库根目录（网页上点 **Add file → Upload files**，把所有文件一起拖进去，然后 **Commit**）。
3. 打开仓库的 **Settings → Pages**，Source 选 **Deploy from a branch**，Branch 选 `main`、目录选 `/ (root)`，点 **Save**。
4. 等一两分钟，页面顶部会出现网址，形如 `https://你的用户名.github.io/pay/`。

## 添加到主屏幕

- **iPhone**：用 **Safari** 打开网址 → 点分享按钮 → **添加到主屏幕**。
- **安卓**：用 **Chrome** 打开网址 → 右上角菜单 → **添加到主屏幕 / 安装应用**。

图标会自动使用文件夹里的还款图标。

## 数据说明

- 数据只保存在**当前设备的浏览器**里，不会上传到任何服务器，仓库公开也看不到你的数据。
- 不同手机、不同浏览器之间的数据不互通。
- 换手机或清理浏览器数据前，点页面右上角的 **↓ 按钮 → 导出备份文件**；到新设备上再用 **从备份文件恢复** 导入。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 网页本体 |
| `manifest.webmanifest` | 主屏幕应用的名称、图标、颜色 |
| `sw.js` | 离线缓存，没网也能打开 |
| `` | 主屏幕和浏览器标签图标 |
| `.nojekyll` | 让 GitHub Pages 原样发布文件 |

修改 `index.html` 后，把 `sw.js` 第一行附近的 `pay-v1` 改成 `pay-v2`，手机上就会更新到新版本。
